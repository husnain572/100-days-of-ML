## Machine Learning (ML) — Definition
Machine Learning is a subset of AI where systems learn patterns from data and improve their performance on a task without being explicitly programmed for every rule.

## When ML is More Useful than Traditional Software

Traditional Software:
- Rule-based (if-else logic)
- Works well when rules are clear and fixed

Machine Learning:
- Learns patterns automatically from data
- Useful when rules are complex, unknown, or change over time

### Examples

1. Email Spam Classifier
- Traditional: Manually define rules (e.g., contains "free", "win")
- ML: Learns from labeled emails (spam/not spam) and improves over time

2. Animal Classifier (Image Recognition)
- Traditional: Hard to define rules for "what is a cat"
- ML: Learns features (ears, eyes, texture) from images


## What is Data Mining?

Data Mining:
- Process of discovering patterns, trends, and useful information from large datasets/

Relation with ML:
- Data Mining = Extract insights from data
- ML = Build models that learn from data

Think:
- Data Mining → "What patterns exist?"
- ML → "Can we predict or automate using these patterns?"

## Short History of Machine Learning

- 1950s: Early ideas (Alan Turing, perceptron)
- 1980s: Neural networks gain attention
- 1990s–2000s: Statistical learning (SVM, decision trees)
- 2010s: Deep Learning revolution (big data + GPUs)
- 2020s+: Generative AI, large language models
